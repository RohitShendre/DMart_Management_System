DMART Management System

Project Overview

DMART Management System is a desktop-based Supermarket Management Application developed using Java Swing, Apache NetBeans IDE, JDBC, and MySQL.

The system is designed to manage supermarket operations such as employee management, receptionist management, product management, billing, and order management.

Technologies Used

- Programming Language: Java
- GUI: Java Swing
- IDE: Apache NetBeans
- Database: MySQL
- Database Connectivity: JDBC
- Architecture: DAO, POJO, and DBUtil

Key Features

1. Login System

- Manager and Receptionist login
- Role-based access to different dashboards

2. Employee Management

- Add new employees
- Update employee details
- Delete employees
- View employee records

3. Receptionist Management

- Add, update, and delete receptionist details
- View receptionist records

4. Product Management

- Add and manage products
- Update product information
- Track available product quantities

5. Billing System

- Add products to customer bills
- Calculate product prices, quantities, and applicable taxes
- Generate customer bills
- Update product stock after billing

6. Order Management

- View customer orders
- Manager can view all orders
- Receptionists can view their own orders

Project Structure

- DAO: Database operations
- POJO: Java model classes
- DBUtil: Database connection
- Swing Frames: User interface screens

How to Run

1. Install Java JDK and Apache NetBeans.
2. Install and configure MySQL.
3. Create the required database and tables.
4. Configure the database connection using the "DMART_DB_PASSWORD" environment variable.
5. Open the project in NetBeans.
6. Build and run the application.

Note: Database setup scripts and sample data may need to be configured separately.
